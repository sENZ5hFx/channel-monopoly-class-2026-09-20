## Primary insight

**Channel-Monopoly Class (CMC).** After the subtractions above, the remaining unknown is that **a channel already assigned one function is treated as full.** Search protocols look elsewhere for a dedicated organ, particle, or gene. The empty search is named as a mystery. The second function was riding the assigned channel.

This is not spoken exaptation (Gould & Vrba 1982). Exaptation is a solved evolutionary concept about how traits originate. CMC is a search-protocol claim: **unsolved mysteries cluster where a channel's first assignment has monopoly over where we are allowed to look.**

**Falsification rule.**

- If locating a *dedicated new* organ / particle / instrument closes the gap → TAC, not CMC.
- If splitting one reported number into two independent observables closes it → OAC, not CMC.
- If changing instrument coupling to a previously uncoupled degree of freedom closes it → CIP, not CMC.
- If recovering a discarded data channel closes it → DCC, not CMC.
- If a time-series of the same object closes it → CIC.
- CMC is confirmed only if **re-analysis of the already-instrumented, already-assigned channel** reveals the second function.

**Duals (do not confuse).**

| Class | Failure mode |
|---|---|
| PPC | too many hidden degrees of freedom |
| OAC | too few independent observables |
| CIP | instrument cannot couple to the DOF |
| DCC | unknown already in the discarded *file* |
| TAC | converter missing; layer named dark |
| **CMC** | **one channel allowed only one function; converter already employed** |

**Pigeon (primary).** Kill CMC if a dedicated non-vestibular magnetoreceptor accounts for homing without the semicircular-canal circuit. **LLSVP.** Kill if composition cannot hide inside observed Vs once T is fixed. Confirm if geoneutrinos, tidal tomography, or noble-gas systematics distinguish Pacific vs African piles as Panton 2025 predicts (Pacific denser, younger SOC).
